# Space Philic · mission presentation

This static package presents an illustrative research and technology demonstration of an orbital laboratory and mission workflow. It includes conceptual spacecraft visuals, model-generated trajectories, planning examples, and simulated telemetry.

Use it for presentations, research discussion, and interface review. It is not an operational simulator or a flight-qualified system. Visual demonstrations do not establish biological outcomes or hardware readiness.

Open `index.html` through a static web server. The laboratory workspace starts at `lab/configure.html`; the recovery review is available at `lab/simulate.html?recovery=canopy`. Some third-party libraries and fonts require an internet connection. Asset attribution is retained in `static/textures/SOURCES.txt` and the bundled license files.

Publish only the contents of this build directory. Keep `.nojekyll` when using GitHub Pages. The package contains no application source repository, private project documents, credentials, or development environment.
